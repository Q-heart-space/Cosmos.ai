# expert/ — 专家角色

Q博士 对外发布的**专家包**——把某个专业角色的视角、方法与提示词打包，供直接提问使用。

## 两类形态

| 形态 | 说明 |
|:--|:--|
| **Expert** | 单一专业角色（如情报分析师 / 反馈专家 / 治理审计员） |
| **Expert Team** | 多角色协作协议（多 Agent 编排） |

## 结构约定

```
expert/<expert-name>/
├── ROLE.md           # 角色定义（视角 / 方法 / 边界）
├── references/       # 该角色的知识 / 清单
└── README.md         # 导入与使用
```
