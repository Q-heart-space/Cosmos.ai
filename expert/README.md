## 🎯 怎么用 / How to use

🅑 **每个专家目录内有 `SKILL.md`**（🅑 或 `plugin.json`）—— 🅑 **那是它的人格与边界声明**。
🅑 **把它交给支持"专家／persona"的宿主**，🅑 它就是那个角色。
🛑 **它不是执行体** —— 🅑 **它给的是视角与方法**；🅑 **实际动手要靠对应技能**（🅑 见 [`../skill/`](../skill/)）。

🅑 **与本域的关系**：🎯 **`expert/` 是"谁来看"·🅑 `skill/` 是"怎么干"** —— 🅑 两者常配对使用。
