# 治理审计团（Expert Team）

> **形态**：Expert Team（多角色协作协议）｜**域**：`expert/`
> **结构依**：`expert/README.md` §结构约定（`ROLE.md` ＋ `references/` ＋ `README.md`）

## 它是什么

一支**有协作流程的审计编队** —— 5 位正交角色，按固定交接链协同，对一套治理体系出**诊断 ＋ 路线图**（🛑 **不出修复动作**）。

## 怎么用

1. 读 **`ROLE.md`** —— 视角 / 方法 / 边界（🛑 先看「不做什么」那条）
2. 读 **`references/团队定义.md`** —— 完整成员表 ＋ 交接链 ＋ 门禁
3. 用它审计时：**按交接链顺序问**，每一步要**上游读数**作依据

- 🛑 **不是执行体**：只声明**成员表 ＋ 协作流程 ＋ 交接判据**；实际编排执行归**编排执行体**
- 🛑 **不出修复动作**：产出是**诊断与路线图**，修复由执行侧承担
