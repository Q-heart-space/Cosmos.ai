# 对外公开库 · `data/` 域

**接收方问题**：🎯 **我要这份可共享的数据**

**状态**：🟡 域已建（契约预留）·内容待产。

## 一、这一域收什么

🎯 **来源支**：`dataset`

## 二、进域判据（🅑 §5.2 之实）

| # | 判据 |
|:--:|---|
| 1 | 🎯 **已脱敏** —— `scope` 明标（如 `shared_deidentified`）**或** 逐字段无主体标识 |
| 2 | 🎯 **有注册表条目** —— 接收方**先知道「有什么」**（`dataset` 之 `.DATA_REGISTRY.md` 为单一真相源） |
| 3 | 🎯 **有 schema／字段说明** —— 接收方**能读懂**（🛑 无说明之裸数据不落） |

## 三、🛑 红线（🅑 无论建不建域皆守）

| # | 红线 |
|:--:|---|
| 1 | 🛑 **他人主体业务数据严禁对外** —— 如 `dataset/ERP-金蝶云星空/`（6 件·§12.1 归属判定） |
| 2 | 🛑 **含私有凭据／账户标识者严禁对外** |
| 3 | 🛑 `_skillhub_meta.json` 存在者严禁发布（§12.2） |
