## 收录判据 / Inclusion criteria

1. 🎯 **已脱敏** —— 每条记录自带共享范围标记，或逐字段无主体标识；
2. 🎯 **有注册表条目** —— 你先知道「有什么」；
3. 🎯 **有字段说明** —— 你能读懂。

## 边界 / Boundaries

- 🛑 **不属于本组织的业务记录不在此域**（🅑 无论是否脱敏）；
- 🛑 含私有凭据／账户标识者不入；
- 🅑 数据以**源仓库为单一真相源**，本域是其**可发布视图**。
