# 来源与边界 / Provenance and boundaries

| 项 | 值 |
|:--|:--|
| **源分支** | `host-adapters` |
| **源路径** | `dsh/profiles/desktop/cordis.patch.yml` |
| **形态 / form** | `plugin`（profile 装载补丁**模板**） |
| **入云方式** | 🅑 **字节拷贝** |

## 为什么它可以对外 / Why it qualifies

| 🎯 轴 | 🎯 判据 | 🎯 实测 |
|:--|:--|:--|
| **产物轴** | 有**与实例无关的可分发定义** | ✅ 是一份**模板** —— 装载项用 **`__QDR_INTENT_ROUTE_PLUGIN_URL__` 占位** |
| **依赖轴** | 重建依赖**全为公开可得**·私有项**外置为自填** | ✅ 🅑 本机路径**仅出现在注释**（🅑 逐字「**原副本写死了** A 机路径…属宿主绑定债」）—— 🎯 **它记的是**曾经的错**·🅑 而**本体已是模板** |

## 怎么用 / How to use

1. 🅑 把 `__QDR_INTENT_ROUTE_PLUGIN_URL__` 换成本机 `plugin.js` 的 **`file://` URL**；
2. 🅑 🛑 **渲染结果不要提交** —— 🅑 渲染值宿主绑定（🅑 提交即制造新的宿主绑定债）。

## 边界 / Boundaries

- 🅑 装载补丁之 `file:///…/plugin.js` 形**两面皆通**；`C:/…/plugin.js` 仅桌面面通；裸包名两面皆不通；
- 🅑 解析失败是**致命**的（🅑 整个 profile 起不来）⇒ 🅑 请勿改其解析形态；
- 🅑 本件是**模板**，🛑 **不含**你机器上的任何路径。
