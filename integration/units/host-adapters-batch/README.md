# 宿主接线批次 / Host adapters batch

> 🎯 **本目录是**一批宿主接线件**之落位说明** —— 🅑 逐件与来源同路径同形。

## 一、🎯 本批含什么

| 🅑 族 | 🅑 例 |
|:--|:--|
| **落位脚本** | 🅑 各宿主之 `bootstrap/install.py` |
| **专家装载模板** | 🅑 `experts/_template/*.yml` ／ 各 `distributions/*/distribution.yaml` |
| **接入片段** | 🅑 `mcp.toml.snippet` ／ `bridge/endpoint.json` 等 |
| **制品构建与同步** | 🅑 `global-memory/` 下之清单与脚本 |

## 二、🎯 怎么用

1. 🅑 **读每件之 `PROVENANCE.md`**（🅑 说清它是什么·🅑 从哪来）；
2. 🅑 **把占位符换为你自己的值**（🅑 `${…}` 形）；
3. 🅑 **按该宿主之文档安装**（🅑 各宿主不同）。

🛑 **两条纪律**：
- 🛑 **渲染后的结果不要提交**（🅑 渲染值**绑定你的机器**·🅑 提交即制造新债）；
- 🛑 **凭据不随件** —— 🅑 需钥匙者按其所指**自填**。

## 三、边界 / Boundaries

- 🅑 本目录**只是落位说明** —— 🅑 各件之详情见其自身；
- 🅑 未随件之件**因其绑定我方设施**（🅑 见 `PROVENANCE.md`）；
- 🅑 本件**不含**任何凭据或渲染后的值。
