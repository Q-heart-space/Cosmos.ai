# 连接件的形状 / The shape of a connector

> **用途**：🅑 判断**一份件算不算连接件**，以及**怎么把它接起来**。
> **口径**：🅑 本件是**形状规范** —— 🅑 它不描述任何**具体**的对端。

---

## 一、🎯 四问（🅑 任何连接件都须能答）

| 🎯 问 | 🅑 合格之形 | 🛑 不合格之形 |
|:--|:--|:--|
| ① **对端是谁**？ | 🅑 以**角色的**说法描述（🅑 如「另一个工作空间」）**＋ 占位符** | 🛑 写死机器名／账户／内网地址 |
| ② **走什么协议**？ | 🅑 具名之公开协议（🅑 如 JSON-RPC over stdio／HTTP） | 🛑 「我方内部约定」 |
| ③ **一件能做什么**？ | 🅑 **动作清单**（🅑 逐条：名字 ＋ 入参 ＋ 出参） | 🛑 只说「能连上」 |
| ④ **钥匙怎么给**？ | 🅑 **你自填** —— 🅑 凭据**不随件**·🅑 由配置文件／环境变量提供 | 🛑 件里带凭据 |

---

## 二、🎯 一件的最小形状

```
<name>/
├── connector.json        # 连接描述（下方字段）
├── actions/              # 逐动作（可选·按需）
└── README.md             # 你怎么用
```

**`connector.json` 必填字段**：

| 字段 | 🎯 含义 | 🎯 例 |
|:--|:--|:--|
| `name` | 件名 | `my-connector` |
| `form` | 🎯 **恒为 `connector`** | `connector` |
| `peer` | 🅑 **对端之角色**（🅑 非地址） | `another-workspace` |
| `protocol` | 🅑 具名协议 | `jsonrpc-stdio` |
| `endpoint` | 🅑 **占位符**（🅑 你自填） | `${PEER_ENDPOINT}` |
| `actions` | 🅑 动作清单 | `[{"name": "...", "in": {...}, "out": {...}}]` |
| `auth` | 🅑 **凭据之来源**（🅑 非凭据本身） | `env:PEER_TOKEN` |

🛑 **禁**：`endpoint` 写死地址 ／ `auth` 写明文凭据 ／ `peer` 写具体机器名。

---

## 三、🎯 接起来的四步

1. 🅑 **落位** —— 🅑 把件放到你的配置目录；
2. 🅑 **填占位** —— 🅑 把 `${…}` 换成**你自己的**值；
3. 🅑 **给钥匙** —— 🅑 按 `auth` 所指，🅑 在你的环境或配置文件里提供凭据；
4. 🅑 **验证** —— 🅑 走一次 `actions` 里的一条，🅑 **并核回执**。

🅑 **第 4 步是唯一算数的一步** —— 🅑 **前面三步都可能"看起来成了"**。

---

## 四、🛑 三条界线（🅑 与相邻形态之别）

| 你别叫它 | 🎯 判据 |
|:--|:--|
| **插件** | 🅑 插件在**宿主内**·🅑 连接件**有对端** |
| **脚本** | 🅑 脚本是**本机**动作入口·🅑 连接件**有对端** |
| **技能** | 🅑 技能是**方法**·🅑 连接件是**通道** |

---

## 五、四条提醒

> **装了连接件 ≠ 获得授权。**
> **读到动作清单 ≠ 能执行它。**
> **接上通道 ≠ 拥有对端全部能力。**
> **描述就绪 ≠ 实机验证完成。**
