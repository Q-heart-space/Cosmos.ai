# 来源与边界 / Provenance and boundaries

| 项 | 值 |
|:--|:--|
| **源分支** | `host-adapters` |

## 为什么它可以对外 / Why it qualifies

| 🎯 轴 | 🎯 判据 | 🎯 实测 |
|:--|:--|:--|
| **产物轴** | 有**与实例无关的可分发定义** | ✅ 清单声明**逐件目标路径 ＋ `sha256`** ⇒ 接收方**可校验并重建** |
| **依赖轴** | 重建依赖**全为公开可得**·私有项**外置为自填** | ✅ **仅标准库**；目标路径用 **`${PLATFORM_CONFIG_DIR}` 占位**（🛑 **不写死**） |

## 它做什么 / What it does

🅑 列出**1 件**要落到该宿主配置目录的文件，🅑 每件带**来源路径 ＋ 摘要 ＋ 目标路径**
—— 🅑 使 **没有治理者**的使用者也能**按清单落位并自校验**。

## 边界 / Boundaries

- 🅑 本件是**落位清单**，🅑 **不含文件本体**（🅑 本体随各自技能/专家包分发）；
- 🅑 目标路径以 `${PLATFORM_CONFIG_DIR}` 表示 ⇒ 🅑 **落位前请替换为你自己的配置目录**；
- 🅑 摘要用于**校验**（🅑 摘要不符即文件已变）。
