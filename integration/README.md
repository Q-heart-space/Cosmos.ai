# integration/ — 接进你系统的单元 / Units you can wire in

> 🎯 **本域面向一个问题**：「**我要把它接进我的系统**」。
> **你怎么找到你要的那个** —— 🅑 **先问自己一句话**：

| 🎯 你的情况 | 🎯 去哪儿 |
|:--|:--|
| 🅑 「**我有一个宿主，要接 Q博士**」 | 🎯 **[`hosts/`](hosts/)** —— 🅑 **一个宿主一个目录** |
| 🅑 「**我要一个能装进系统的功能件**」 | 🎯 **[`units/`](units/)** —— 🅑 与宿主无关的可装载件 |

---

## 一、🎯 `hosts/` —— 一个宿主，一个目录

🅑 **每个宿主目录内是同一种结构**（🅑 你看一个就知道全部）：

| 🅑 里面有什么 | 🎯 它是干什么的 |
|:--|:--|
| 🅑 `manifest.json` | 🎯 **落位清单** —— 🅑 逐件给 `src`（来源）／ `sha256`（摘要）／ `dst`（目标） |
| 🅑 `PROVENANCE.md` | 🎯 **来源与边界** —— 🅑 它从哪来·🅑 什么没随件 |
| 🅑 `payload/` | 🎯 **本体** —— 🅑 真正要落位的东西（🅑 装载脚本 ／ 专家模板 ／ 接入片段） |
| 🅑 `subfaces/`（🅑 部分宿主有） | 🅑 **该宿主的附加面**（🅑 如桌面版 profile） |

## 三、🎯 怎么用（🅑 四步）

1. 🎯 **看你是哪种情况**（🅑 上表第一格）⇒ 🅑 进 `hosts/` 或 `units/`；
2. 🅑 **进对应目录** ⇒ 🅑 读其 `manifest.json` 之 `files[]`（🅑 每项给 `src` ／ `sha256` ／ `dst`）；
3. 🅑 **把 `dst` 里的 `${PLATFORM_CONFIG_DIR}` 换为**你自己的**配置目录；
4. 🎯 **落位后核摘要** —— 🅑 不符即文件已变。

🛑 **若你要的宿主不在 `hosts/` 里** ⇒ 🅑 **它尚不可独立装载**（🅑 见「边界」）。

---

## 四、🎯 收录判据 / Inclusion criteria

1. 🎯 **产物轴** —— 🅑 存在**与实例无关**的可分发定义（`manifest` ／ `schema`），使你能**重建等价实例**；
2. 🎯 **依赖轴** —— 🅑 重建依赖**全为公开可得**；🅑 私有项已**外置为你自填的配置**；
3. 🎯 **形态** —— 🅑 以 `form` 字段标明（`mcp` / `plugin` / `connector` / `automation`）。

---

## 五、🛑 边界 / Boundaries

- 🛑 **实例运行态**（🅑 会话、凭据、机器标识）**不随件发出**；
- 🛑 **依赖不清者不入**；
- 🅑 本域只收**能独立装载**的单元，🛑 不收「在本组织内才跑得起来」的东西；
- 🎯 **`manifest.json` 是清单·🅑 `payload/` 是本体的分界** —— 🅑 清单给**摘要与目标**，
  🅑 本体给**内容**；🅑 **两者都在本域内**（🅑 你看得见全部）。
- 🅑 **落位前请替换占位符** —— 🅑 本域不含任何**渲染后的机器值**。
