# 第一原理：为什么有些信号永远做不到

本文件推导 `SKILL.md` 的 **Tier A / B / C** 分层。
它不是设计偏好，是从 agent loop 的结构里推出来的——所以它能解释**为什么某些信号无论怎么写都到不了 Tier A**。

---

## 1. 一次 agent 回合，只有这几个接缝

```
用户消息
  │
  ├─[缝1 上下文装配]────── 我能往上下文里放文字
  │
  ├─[缝2 pre-step]──────── 我能拒绝这一步 / 换掉进入模型的 messages
  │
  ├─ 模型推理 ──────────── 我插不进去（这是权重，不是配置）
  │
  ├─[缝3 pre-dispatch]──── 我能 allow / deny / ask
  │
  ├─ 工具执行
  │
  ├─[缝4 post-dispatch]─── 我能改结果 / 追加上下文
  │
  └─[缝5 提交 / CI]─────── 我能拒绝合入
```

## 2. 一条规则能有多硬，取决于它挂在哪个缝上

**不取决于它写得多好。** 这是全部推导的起点。

| 挂在哪 | 保证 | Tier |
|:--|:--|:--|
| 缝1 | 文字在上下文里（**在某处**） | **C** |
| 缝2 / 缝4 | 内容**必然出现在正确的时刻**；或模型对"发生了什么"的认知由我决定 | **B** |
| 缝3 / 缝5 | 动作**不会发生** | **A** |

「写在 SKILL.md 里」= 缝1。所以**一份技能，结构上就不可能是 Tier A**。
要拿到 Tier A，必须交付**宿主侧的钩子**，而那已经不是"技能"这个形态了。

## 3. 判据：触发谓词必须是该缝可观测量的全函数

缝能看到：工具名、参数、路径、文件字节、用户消息文本、本轮计数、台账集合。
缝**看不到**：意图、"这算不算过度设计"、"模型刚才有没有想过 X"。

于是每个信号的可达上限立刻确定：

| 信号 | 触发谓词 | 是可观测量的全函数？ | 上限 |
|:--|:--|:--|:--|
| S5 | 内容匹配 `{word}` 且路径 `.html` | ✅ 字节级 | **A** |
| S4 | basename ∈ 集合 ∧ ∉ 台账 | ✅ 集合运算 | **A** |
| S9 | 消息**精确等于**停止词 | ✅ 精确匹配 | **A** |
| S10 | 本轮新建文件数 ≥ N | ✅ 计数 | **A / B** |
| S8 | todo 存在未完成项 | ✅ 读状态 | **B / A** |
| S6 | 本轮有编辑 ∧ 即将收尾 | ✅ 计数 + 时机 | **B**（"有没有扫"不可判） |
| S3 | "模型与任务是否匹配" | ❌ 判断 | **B**（"破坏性操作前确认"可 A） |
| S7 | "他确认的究竟是什么" | ❌ 判断 | **B**（"短确认后对不可逆操作确认"可 A） |
| S1 | "用户其实只想要一段文字" | ❌ 判断 | **B** |
| S2 | "他该不该反问" | ❌ 判断，且失败发生在**输出**层 | **B** |
| 工程化 vs 渐进式 | "值不值得建一个系统" | ❌ 价值判断 | **C** |

**注意 S2**：它不是"还没脚本化"，而是**失败发生在输出层**。而输出层只有 emit 可观察，没有否决权——所以它连 B 的机制都只能挂在**上游**（缝2 注入），拦不住"多问一句"本身。

## 4. 成本模型决定了 A 的准入门槛

守卫的摩擦是**连续支付**的，收益是**概率性**的。所以：

> **误报的代价 > 漏报的代价。**
> 一个会拦住正常工作的守卫，第二天就会被关掉——它的有效保护时间趋近于零。

这推出 A 的准入条件：**误报率必须 ≈ 0**，也就是谓词要像字节匹配、精确 token、集合成员那样干净。

把不可判的规则硬做成 A，产出的不是"更强的守卫"，是"更早被卸载的守卫"。

## 5. 守卫的比较优势

模型在一轮长对话里会**丢失记账**：这是第几个新文件、这个文件名扫过没有、上一步改的是哪个配置。这些"机器一算就准，模型记不住"。

> **脚本化该做机器算得准、模型记不住的事；判断留给模型。**

这句话比"能脚本化的就脚本化"更严格：它排除掉那些**机器算了也不准**的东西（意图、价值），也排除掉那些**模型自己就够准**的东西（不该管的别管）。

## 6. 结论

| Tier | 准入门槛 | 谁该做 |
|:--|:--|:--|
| **A** | 谓词可判 ∧ 误报≈0 | 宿主钩子（本技能的适配器） |
| **B** | 谓词可判，但结论是**建议**而非**裁决** | 宿主钩子，注入而非拒绝 |
| **C** | 谓词不可判 | 写进 `AGENTS.md`，别指望强制 |

**永远做不到 Tier A 的**：意图判断、价值判断、以及任何失败发生在"模型输出文本"层的规则。

这不是本技能的缺陷。**这是所有基于提示或钩子的方案共同的天花板。**
