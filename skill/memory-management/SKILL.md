# 记忆管理 —— 五层防线

> **它解决什么**：🅑 AI 的"记忆"很容易变成**一堆互相矛盾的碎片**。
> **它的立场**：🎯 **记忆的价值在**可追溯**·🅑 而不在"记得多"**。

---

## 一、🎯 五层

| 🎯 层 | 🎯 职责 |
|:--|:--|
| **L0 权威源** | 🅑 哪一份是**正本**（🅑 其余皆为派生） |
| **L1 强制加载** | 🅑 开工前**必须读**哪些（🅑 **没读完不许动手**） |
| **L2 写前路由** | 🅑 这条信息**该记去哪儿**（🅑 不是所有事都进同一份） |
| **L3 归因写入** | 🅑 **为什么记**（🅑 无归因的条目 = 未来的噪音） |
| **L4 回溯审计** | 🅑 定期回看：🅑 **哪些过时了／哪些互相矛盾** |

---

## 二、🎯 三条纪律

| 🛑 | 🎯 行 |
|:--|:--|
| 🛑 **正本唯一** | 🅑 同一事实**只有一个正本**·🅑 其余标"派生" |
| 🛑 **写入须归因** | 🅑 记一条**要能说清为什么** —— 🅑 否则不记 |
| 🛑 **过时须撤** | 🅑 **不撤的过时条目 = 定时炸弹** |

## 四、边界 / Boundaries

- 🅑 本件是**方法** —— 🅑 与具体产品无关；
- 🅑 层级多少可**按你的需要增减**（🅑 五层是常见够用的规模）；
- 🛑 本件**不**规定你该记什么内容 —— 🎯 **那是你的判断**。
