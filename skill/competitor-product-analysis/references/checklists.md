# checklists.md — P0~P4 预检·验收·定级·常见失误

> 本文件由 SKILL.md 按需加载（Step 0 预检 / Step 7 验收时）。不加载不影响主流程。
> 版本：v1.5.0 | 2026-09-15

## 一、P0~P3 预检清单（数据输出前强制）

### P0 — 产品参数逐项溯源
- [ ] 每项参数有来源 URL（可反查·非「advantech.com 产品页」模糊表述）
- [ ] 标注抓取时间
- [ ] **无来源 URL → 停止补抓**（唯一阻断项）

### P1 — 关键结论逐条归属
- [ ] 每条结论明确标注归属竞品
- [ ] 禁止无主结论（「某厂商在同类中偏弱」这类无主表述）

### P2 — 交叉验证
- [ ] ≥2 个**独立**信息源（同主体不算：官网与其公众号属同一主体）
- [ ] 多语言站交叉（原始国语言站 + 英文全球站）

### P3 — 准确性声明
- [ ] 结论标注置信度（高/中/低）
- [ ] 不确定项显式标注，不臆断

## 二、P4 交付分级（A/B/C/阻断）

| 级别 | 标准 | 输出约定 |
|:--|:--|:--|
| **A 级** | 全部竞品达标 | 正常交付 |
| **B 级** | ≥6/8 达标 | 交付 + 附《补抓清单》 |
| **C 级** | <6/8 达标 | 需返工，不交付 |
| **阻断** | P0 未通过 | 停止，补抓 |

## 三、事后验证清单（完成后必跑）

- [ ] 报告文件真实落盘**调用方空间**（非 Q博士 空间）
- [ ] 来源 URL 可点击反查
- [ ] 认证数据标注来源 + 是否「已外部验证」
- [ ] 时效状态已标注（四级规则）

## 四、常见失误表

| # | 失误 | 后果 | 防法 |
|:--|:--|:--|:--|
| 1 | 只查英文站 | 漏认证（Moxa 教训） | 多语言站交叉 |
| 2 | 多列规格看错列 | 数据错配（E7S 判例） | rule-5 逐行锁定 |
| 3 | 营销值当 SKU 值 | 虚高（MIC-733-AO 37.5%） | 单 SKU vs 系列分离 |
| 4 | 跨路线算力直接排序 | 错误结论（x86 vs Jetson） | rule-6 量纲校验 |
| 5 | 同主体源算两源 | 假交叉验证 | 信源分级 + 同源判定 |
| 6 | 单源竞品硬写结论 | 不可验证 | 拿不到两源就刻意不写 |

## 五、回写契约

每发现新失误 → 按模板回写 `case-law.md` → SKILL.md 版本号 +0.0.1 → 《版本演进表》加一行。
