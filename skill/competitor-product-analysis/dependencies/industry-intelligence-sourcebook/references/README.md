# Industry Intelligence Sourcebook — 扩展指南

## 何时更新此技能

- 发现新的高价值信源（厂商官网/展会/标准组织/行业媒体）
- 现有信源质量变化（升级/降级L1-L4层级）
- 发现新的竞品厂商
- 展会日历更新（新增/调整展会信息）
- 搜索词模板失效
- 需要新增行业

## 如何新增行业

1. 复制 `sourcebook.schema.json` 中的模板结构
2. 创建 `{industry}_sourcebook.json`
3. 填充内容：L1-L4信源 → 竞品清单 → 展会日历 → 搜索白名单 → 搜索词模板 → 交叉验证映射 → 评分规则
4. 更新 `../SKILL.md` 中的"支持行业"表格
5. 通知所有引用此技能的项目/自动化
