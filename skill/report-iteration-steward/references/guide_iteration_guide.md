# 操作手册/指南迭代指南

> **版本**：v1.0 | **日期**：2026-07-06 | **用途**：扩展 report-iteration-steward 到操作手册/指南的迭代
> **适用场景**：多章节、多人协作的操作手册（如 README、操作手册、方法论指南）需要扩充章节或重构时

## 与报告迭代的差异

| 维度 | 报告迭代 | 手册/指南迭代 |
|:--|:--|:--|
| **版式审查** | 布局/图表/品牌色 | 目录完整性/章节编号/交叉引用 |
| **模块完整性** | 是否有缺页 | 是否有缺章节/缺步骤 |
| **版本一致性** | 前后结论无矛盾 | 前后流程无断点/引用与实际一致 |
| **阶段验收** | 内容/格式/构建 | 读者导航完整/链���有效/版本头正确 |

## Step 1.5 手册章节放置评估

```
概念层（前置）：为什么需要这个指南、谁应该读、工作原理 → 放在开头章节
操作层（核心）：具体步骤、代码示例、截图 → 放在中间章节
参考层（附录）：FAQ、错误码、版本历史 → 放在末尾章节
```

## 手册迭代关键检查项

1. **章节编号全量扫描**：新增章节后编号是否连续
2. **交叉引用验证**：所有"见XX节"引用是否指向正确目标
3. **读者导航完整性**：目录能否覆盖所有新增内容
4. **版本头同步**：所有子文件的版本号是否与主文件一致
