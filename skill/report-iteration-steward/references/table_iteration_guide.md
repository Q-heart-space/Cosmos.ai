# 表格/在线表格迭代指南

> **版本**：v1.0 | **日期**：2026-07-06 | **用途**：扩展 report-iteration-steward 到 Excel/在线表格的迭代
> **适用场景**：多字段、多模块的在线表格（企微表格、腾讯表格等）需要增删字段或重新分区时

## 与报告迭代的差异

| 维度 | 报告迭代 | 表格迭代 |
|:--|:--|:--|
| **版式审查** | 布局/图表/ 品牌色 | 字段位置/列宽/冻结/过滤 |
| **模块完整性** | 是否有缺页/缺图 | 是否有缺列/缺字段/缺数据 |
| **版本一致性** | 前后结论无矛盾 | 前后公式无断裂/数据源一致 |
| **阶段验收** | 内容/格式/构建 | 字段覆盖/公式正确/数据刷新 |

## Step 1.5 表格内容放置评估（三段式分类法的表格版本）

```
分析层（A 区）：原始数据字段、时间戳、来源标注 → 放在前面列
洞察层（B 区）：汇总指标、趋势标红、AI 摘要 → 放在中间列
行动层（C 区）：待办清单、跟踪状态、责任人 → 放在末尾列
```

## 表格迭代关键检查项

1. **字段唯一性**：新加字段不与其他字段含义重复
2. **公式继承**：新增行/列时，公式是否自动继承
3. **过滤兼容**：现有过滤条件对新数据是否有影响
4. **数据源一致性**：字段值来源是否与现有字段一致
