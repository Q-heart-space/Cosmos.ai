# 决策单元

> **它解决什么**：🅑 决策做了就忘了为什么 —— 🅑 **下次遇到同类事·🅑 又从头吵一遍**。
> **它的立场**：🎯 **一个决策 = 一个单元** —— 🅑 **有依据·🅑 有选项·🅑 有取舍·🅑 有复盘点**。

---

## 一、🎯 一个决策单元含什么

| 🎯 字段 | 🎯 问什么 |
|:--|:--|
| **问题** | 🅑 要定的到底是什么（🅑 一句话·🅑 **不许含糊**） |
| **依据** | 🅑 支持它的**事实**（🅑 不是意见） |
| **选项** | 🅑 至少两个（🅑 **只有一个 = 不是决策·🅑 是通知**） |
| **取舍** | 🅑 为什么选这个·🅑 **放弃了什么** |
| **可逆性** | 🅑 做错了**能不能退**（🅑 不可逆的 ⇒ **须更慎重**） |
| **复盘点** | 🅑 **什么时候回来看它对不对** |

---

## 二、🎯 三条纪律

| 🛑 | 🎯 行 |
|:--|:--|
| 🛑 **选项少于两个 ⇒ 不算决策** | 🅑 那是执行·🅑 不是选择 |
| 🛑 **不可逆的须写清退路** | 🅑 没退路的决策·🅑 要更慢 |
| 🛑 **须留复盘点** | 🅑 **不设时间点的复盘 = 不会有复盘** |

---

## 四、边界 / Boundaries

- 🅑 本件是**结构化方法** —— 🅑 不替你判断该选哪个；
- 🅑 字段可**按需增减**（🅑 但"选项"与"复盘点"建议保留）；
- 🅑 本件**不含**任何具体决策记录。
