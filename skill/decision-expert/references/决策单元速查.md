# 决策单元速查（decision-expert 参考）

> 🛑 本文件是**速查与口径**，**不是**规范本体。规范/模板/条目一律以下列**仓内真相源**为准（改口径改那里，不改本文件）：
> - `constitution/本质定位.md` **L313/L315**（三元组 × 五链·宪法锚）
> - `constitution/决策OS规范.md`（三维矩阵 T0–T5 × 类型 × 影响范围）
> - `governance/templates/decision_asset_sixpiece_template.md`（六件套模板）
> - `audits/2026-09/[决策资产]QDR-DEC-001_决策能力载体选型_B机_20260926.md`（本专家的载体选型裁决）
> - `drq/expert/expert_lib.json` 的 `EXP-DECISION`（对外注册条目）
> - 判据器：`scripts/decision_quality_auditor.py`（六问/回测）·`scripts/decision_os_gate.py`（入口闸门）·`scripts/decision_trigger_validator.py`（触发面完整性）

## 一、六件套（一份决策资产至少要有这六件）

| # | 件 | 判"有"的标准 |
|:--|:--|:--|
| 1 | 决策依据 | 第一原理/第一定律 + **外部情报交叉验证**（不是"惯例如此"） |
| 2 | 替代方案评估 | **至少 2 个被认真评估的替代方案**，各写"为何不选" |
| 3 | 验收标准 | **可复算读数**（含分母/口径/时间点），不是"感觉好" |
| 4 | 回滚与失效条件 | 什么条件下必须撤回（**可比对的触发条件**） |
| 5 | 授权链 | 谁有权定这件事（越权即无效） |
| 6 | 收据链 | 落盘路径/提交号/回读读数（事后可反查） |

## 二、决策六问（判合格用·`--six-questions`）

1. **域**——属哪类决策（类型轴）？2. **定律**——从第一原理推的还是抄惯例？3. **外情**——查外部情报没有？4. **读数**——验收可复算吗？5. **结论**——显式吗（含不选的理由）？6. **回滚/失效**——触发条件写了吗？

**A/B 回归**（回测存量件）：**A**＝未查既有真相源（重复实现/重复裁决）｜**B**＝未跑该件自己声明的判据（只声明不验收）。

## 三、三维矩阵（定层级）

- **层级**：T0（最高/最不可逆）→ T5（最低）。判据＝影响面 × 不可逆性，**不得自封**。
- **类型**：选型 / 排期 / 归属 / 口径 / 处置 / 退役 / 载体选型…
- **影响范围**：单件 / 单机 / 跨机 / 跨空间 / 对外。
- **不匹配即不合格**：低层级处理高影响面（越权），或高层级处理单件琐事（过度）。

## 四、命令速查（治理根执行）

```bash
python scripts/decision_quality_auditor.py --self-test                  # 判据自检（rc=0 才可信）
python scripts/decision_quality_auditor.py --six-questions <件>          # 六问判合格
python scripts/decision_quality_auditor.py --backtest audits/2026-09     # 全量回测（点名缺项+A/B）
python scripts/decision_os_gate.py --file <件> --operation manual        # 入口闸门（C-30）
python scripts/decision_trigger_validator.py                             # 触发面完整性（7 信号）
```

## 五、退出码语义（🛑 三态必须分清）

`0` 通过 · `1` 仅提示 · `2` 有阻断项 · **`3` 判据不可用**（件/目录缺失 ⇒ `[rc3-class] class=env_not_ready`）。
**rc=3 是"未判"，不是"通过"**——不得把不可用读成合格（同族反模式 #57/#118）。

## 六、常见误用（判例）

1. **只写结论不写不选项** ⇒ 六问第 5 问不过；事后无法复盘"为什么没选 B"。
2. **验收标准无分母** ⇒ 第 4 问不过；读数不可复算＝无法验收。
3. **回滚条件写成"视情况而定"** ⇒ 第 6 问不过；等于没有回滚点。
4. **把"决策"当"计划"** ⇒ 决策＝在多个方案间选择并承担代价；计划＝把一个方案拆成步骤。前者归本专家，后者归 `task-retrospective` / 规划表。
5. **越权裁决**（低层级窗口定跨空间/对外事项）⇒ 授权链缺失，件无效，须回退到有权层级重定。
