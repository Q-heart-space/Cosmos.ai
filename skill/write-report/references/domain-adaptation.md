# 新领域适配流程（domain-adaptation.md）

> 补充 `write-report` 技能——把通用研究报告方法论迁移到新领域时的适配步骤。

## 适配流程（五步）

1. **识别领域锚点**：该领域的核心维度（客户/竞品/技术/认证/政策）有哪些？与通用框架的差异在哪？
2. **收集来源清单**：官网（A）、行业报告（B）、媒体（C）——优先官方渠道（铁律 AB 数据源权威层级）。
3. **定义章节模板**：在通用结构上增删领域特有章节（如海事加「认证门槛」，医疗加「注册审批」）。
4. **沉淀领域示例**：产出一份领域示例（对标 `examples-maritime.md`），供后续复用。
5. **回填 check-dimensions**：若新领域有特有校核维度，补充到 `check-dimensions.md`。

## 适配原则

- **复用通用框架**：五维校核、Patch 修订、来源分级（A/B/C/D）是跨领域通用的，不改；
- **只增删领域层**：章节模板、来源清单、示例是领域层，随领域增删；
- **防重复造轮子**：新领域适配前先查是否有同类领域示例可参考（铁律 BR 建前查存量）。
