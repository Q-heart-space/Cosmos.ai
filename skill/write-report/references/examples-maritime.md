# 海事工控机领域示例（examples-maritime.md）

> 补充 `write-report` 技能的领域示例——海事工控机研究报告的标准结构与要点。

## 标准章节结构

1. **行业概述**：海事工控机定义、应用场景（船载导航/机舱监控/岸基调度）、市场空间
2. **竞争格局**：主要玩家（对标森克等）、市占率、产品线对比
3. **技术演进**：加固等级（IP67/宽温）、通信协议、算力平台趋势
4. **需求与机会**：客户痛点、国产替代窗口、切入策略
5. **风险与建议**：认证门槛、认证周期、竞争风险

## 领域特有要点

| 维度 | 海事工控机特性 |
|:--|:--|
| 环境 | 高盐雾、宽温、振动、EMC（须 IP67/宽温加固） |
| 认证 | CCS/DNV 等船级社认证是准入门槛 |
| 客户 | 船厂、航运公司、系统集成商（决策链长） |
| 竞品 | 对标森克等嵌入式 BOX 厂商（见 competitor-product-analysis 技能） |

## 报告示例片段

> 「海事工控机对**加固等级与认证**的权重显著高于通用工控机。CCS 认证周期约 12-18 个月，构成新进入者的主要时间壁垒。国产替代窗口集中在船载导航一体机与机舱监控网关两类设备。」

> 来源分级示例：市场空间数字标 `B 行业报告`；竞品参数标 `A 官网`；机会判断标 `D 推测（须标注）`。
