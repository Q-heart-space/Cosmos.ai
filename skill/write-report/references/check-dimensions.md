# 五维校核详细说明（check-dimensions.md）

> 补充 `write-report` 技能的「五维校核」详细说明。撰写阶段自检，**不替代 coherence**（内容自洽由 apq-content-coherence 承担）。

## 五维清单

| 维度 | 校核内容 | 时机 |
|:--|:--|:--|
| ① 前后一致性 | 同一数据/结论在全文各处是否一致（数字、名称、口径） | 每章完成时 |
| ② 趋势逻辑 | 数据变化方向是否自洽（增长/下降不矛盾、同比环比不打架） | 全章完成后 |
| ③ 结论可追溯 | 每个结论是否可回溯到来源数据（A=官网/B=行业报告/C=媒体/D=推测） | L2 深度审 |
| ④ 竞品完整性 | 竞品对比是否覆盖关键维度、无遗漏对标对象 | P2 大纲规划时 |
| ⑤ 盲区检测 | 是否有数据空白/未覆盖维度，是否诚实标注「未知」 | P2+P4 |

## 来源分级（④ 结论可追溯的依据）

| 级 | 来源 | 可信度 |
|:--|:--|:--|
| A | 官网 / 年报 | 高 |
| B | 行业报告 | 中 |
| C | 媒体 | 中低 |
| D | 推测 | 低（须标注） |

## 使用规则

1. 五维校核是**撰写阶段自检提示**，发现问题就地修正；
2. 校核通过 ≠ 内容自洽——**内容逻辑矛盾由 apq-content-coherence 单独承担**；
3. 盲区检测（⑤）诚实标注「未知/待验证」优于强行填数（对齐反模式「规模数字先实测」）。
