# 宪法架构前置判决 · 简化模板

> 本模板从 `SKILL.md`「宪法架构前置判决」四题提炼，供每个审计 Agent 输出时实体化三字段：宪法前提概念名、决策OS层级、第一原理锚定点。
> 修复来源：`SKILL.md` L57 引用 `references/constitutional_anchor_template.md` 但文件缺失（悬空引用·0A-R A1-1）。

## 每个 Agent 输出必须含以下三字段

| 字段 | 说明 | 取值示例 |
|:--|:--|:--|
| **宪法前提概念名** | 本次审计涉及的最高宪法概念 | 交付物语义级联 / 即时联动 / 关系本体 / 第三空间 |
| **决策OS层级** | 本次发现归属哪个决策层 | T0 宪法级 / T1 战略级 / T2 架构级 / T3 方法级 / T4 操作级 |
| **第一原理锚定点** | 结论可追溯到哪个第一定律/四心进化 | 第一定律「升级自己即升级所有空间」/ 信息↔决策第三空间 |

## 四题判决（任何审计启动前必须通过）

1. **宪法前置法**：审计对象涉及的最高宪法概念是否存在？
   - 概念不存在 → 停止审计·先补宪法·不得绕过
   - 概念存在但版本不对 → 报告中标注「概念基础已过时」
2. **决策OS路由**：发现属于哪个决策层？
   - T0 → 停审计·等人确认·不得自动修复
   - T1 → AI 提出方案·等确认
   - T2 → AI 修复·事后审计验证
   - T3 → AI 修复·记录
   - T4 → 脚本自动修复
3. **第一原理锚定**：结论是否可追溯到第一定律或四心进化？
   - 有操作层发现但无宪法锚定 → 标注「未锚定·宪法补救建议」
   - 有宪法级发现 → 必须引用具体宪法文件章节号
4. **记忆完整性**：本次宪法级变更是否已写入全部记忆层？
   - 流程日记 / 成长记录 / L3 日志 / L2 MEMORY.md 四层
   - 任一缺失 → P0·停止审计·先补记忆
