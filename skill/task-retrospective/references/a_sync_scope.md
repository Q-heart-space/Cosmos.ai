## 同步范围扩展（新增·2026-06-27·🆕 2026-07-24 补全 Q博士 写入目标）

> ⚠️ **来源**：用户要求复盘后同步修正"跨项目、跨任务的脚本、规则、记忆、技能、专家"。
> 🆕 **2026-07-24 补全**：全局修订产出必须写入 Q博士 的四层交付物，不可遗漏。

每次复盘修复后，同步范围从原来的"技能+脚本+规则+记忆"扩展为：

| 同步对象 | 检查内容 | 工具 |
|:--|:--|:--|
| 脚本（*.py） | 硬编码列号、旧字段名、过时逻辑 | Grep / Glob |
| 规则（MEMORY.md） | 过时规则、不可执行规则、命名冲突 | Read + Grep |
| 记忆（daily log） | 当日日志是否记录了修复 | Read + Edit |
| 技能（SKILL.md） | 步骤是否过时、是否缺少新规则 | Read + Edit |
| 专家（Expert configs） | 专家配置中是否有过时引用 | Glob <宿主配置根>/experts/ |
| 跨项目 | 其他项目是否有同类缺陷 | 检索**各工作空间**之记忆目录（🅑 `Glob <工作空间根>/*/.<配置目录>/mem`）ory/ |
| 跨对话 | 历史会话是否重复出现同类问题 | conversation_search |
| 自动化任务 | automation 中 modelId 是否正确 | automation_update(mode="list") |
| 🆕 **drq/patterns/** | 将可复用模式写入 Q博士 模式库 | Write `drq/patterns/{domain}/{name}.md` |
| 🆕 **drq/meta_patterns/** | 将元模式写入 Q博士 元模式库·**全自动全链路** | `python -c "from register_meta import register_meta; register_meta({'title':'...','tier':1,'problem':'...','core_insight':'...','source':'retrospective'}, auto_bridge=True)"`（自动完成 JSON→index→bridge→plan·不等22:00） |
| 🆕 **constitution/综合工作规划.md §三** | 新任务追加到 Q博士 宪法主表 | Read + Edit |
| 🆕 **<宿主配置根>/MEMORY.md** | 全局铁律升级 | Read + Edit |

### 🆕 "全局修订"三层分流前置步骤（收录标准指引·2026-07-25 入宪法）

> **来源**：2026-07-24 业务空间执行全局修订时，收录标准（`governance/Q博士_任务同步与规划写入标准.md`）对业务空间 AI 不可见 → 导致 8 条任务未按三层分流全部挤入 §三主表。
> **宪法依据**：跨空间本体论 §3 最原点需求=跨空间复用 → Distribute 管道必须完整。本质定位 §1.4·C 递归闭环=产出即自省。战略宪章 P1-13 人类不追问=已闭环 → 业务空间 AI 必须能自动判断写入位置。

**触发条件**：AI 检测到「全局修订」/「Q博士，全局同步」触发时，在四层写入之前强制执行。

**强制步骤**：

```
Step S0·收录标准加载 + 跨空间影响判定:
  1. 🆕 运行跨空间影响扫描器（工程化·T-2-034）：
     python scripts/cross_space_impact_scanner.py --changed "<变更文件路径>"
     → 判定：是否需要触发全局修订？（exit 1=需要，exit 0=不需要）
     → 输出：命中维度/影响等级/受影响空间清单
  2. 读取 governance/Q博士_任务同步与规划写入标准.md §二「同步范围：三层模型」
  3. 按以下三层分流矩阵判定每个产出：

Step S1·三层分流矩阵:
  ┌────────────┬──────────────────────────────────┬──────────────────────────────────┐
  │ 产出类型   │ 判定标志                          │ 目标位置                         │
  ├────────────┼──────────────────────────────────┼──────────────────────────────────┤
  │ 📚 知识级  │ patterns/meta-patterns/规则/案例  │ drq/ + 综合规划 §〇关键数字        │
  │ 🛠️ 工具级  │ 脚本修改/脚本新建/工具链变更       │ 自检登记表 + 综合规划 PM  │
  │ 📋 方法级  │ SOP/路径修复/协议入册/方法论升级   │ task-retrospective + 综合规划 §〇  │
  │ 📋 任务级  │ 全新独立任务（不属上述三类）       │ 综合规划 §三 主表（唯一）          │
  └────────────┴──────────────────────────────────┴──────────────────────────────────┘

Step S2·禁止行为:
  - ❌ 不读取收录标准就写入任何位置
  - ❌ 知识级/工具级/方法级产出挤入 §三主表
  - ❌ 仅写入 versions/ 而不写入 constitution/§三
```

**验收**：全局修订完成后，§三主表中新增项仅包含「全新独立任务」，其他类型已按矩阵分流到正确位置。
