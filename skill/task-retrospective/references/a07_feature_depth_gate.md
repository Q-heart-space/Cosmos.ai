## 🆕 Step A0.7：功能深度门禁（新增·2026-07-10·根治浅层功能反复升级）

> ⚠️ **来源**：九维追问发现——AI 建功能常停留在"基本能用"，用户后续发现边界/验收/关联/元问题未处理，被迫反复升级。根因：开工前没有强制设计深度评估。

**若本次任务涉及新建/重构脚本、技能、规则、自动化或任何非临时性交付物，构建前必须**：

1. 先写设计文档，覆盖十维：
   - D1 真问题定位 · D2 边界穷尽 · D3 失败模式预测 · D4 验收可验证
   - D5 关联扫描完整性 · D6 防复发机制 · D7 元问题触及 · D8 演化预留
   - D9 名实一致 · D10 可复用/标准化
2. 运行门禁脚本：
   ```bash
   python scripts/feature_depth_gate.py --file <设计文档路径>
   ```
3. 按评分决策：
   - < 60 → 🛑 阻断，禁止开工，补设计
   - 60-79 → ⚠️ 警告，补强 Top-3 缺口后再构建
   - ≥ 80 → ✅ 通过，进入构建
4. 构建完成后，用设计文档中的验收标准验证，禁止仅凭"感觉完成"标记闭环
