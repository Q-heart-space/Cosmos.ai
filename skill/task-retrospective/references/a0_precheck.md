## 🆕 Step A0：方法选择审计（前置，2026-07-01 确立）

> ⚠️ **来源**：跨项目复用任务用了 3 轮探索才找到正确工具（探索Agent→report-iteration-steward→task-retrospective），根因是没有"场景→工具"映射。

每次复盘启动前，先执行方法选择审计：

```
1. 提取任务类型：跨项目复用 / 报告迭代 / 规则修复 / 数据刷新 / 其他
2. 查询 task-router 方法选择矩阵 → 找到对应的正确工具
3. 对比实际使用的工具 → 是否匹配？
4. 不匹配 → 记录：
   - 浪费轮次
   - 为什么用了错的
   - 是否需要补充方法选择矩阵
5. 输出：《方法选择审计》→ 在复盘报告中单独一段
```

**执行规则**：
- 如果方法选择矩阵中不存在该任务类型 → 本次复盘结束后更新矩阵
- 如果方法选择矩阵存在但被忽略 → 检查 AI 自检 #13 是否执行
