# 技能审阅输出模板（references/templates.md）

> 用途：Step 5/7 的标准输出格式。所有审阅产出按此模板，保证同事可读、可执行、可验收。

## 1. 审阅报告头（边界声明必填）

```markdown
# <技能名> 审阅报告（<日期>）

> **审阅边界**：A 象限（技能本体）；B/C/D 象限问题已另行处理/登记（附去向）。
> **审阅方法**：skill-review 标准化流程（Step 0-7）
> **证据基线**：E1..En（实测时间/命令/输出摘要）
```

## 2. 两审问题清单

```markdown
| ID | 视角 | 问题 | 证据 | 优先级 | 来源 |
|----|------|------|------|:--:|------|
| A1 | 审2-D6 | 双份资产漂移 | E3：工作区 330 行 vs 已装 365 行 | P0 | 本体审阅 |
```

## 3. 任务五段式（每个 P0/P1 任务完整展开）

```markdown
### <ID> <任务名> 【<优先级> · <执行人> · <依赖>】

- **[问题]**：现状缺陷（一句话 + 证据引用）。
- **[方向]**：修复思路（为什么这么做，源自什么方法论 M#/X#）。
- **[方案]**：具体动作（写入哪个文件/哪个协议/哪段流程，可照做）。
- **[验收]**：可测判定（回归场景/样例输出/字段检查）。
- **[执行人]**：AI / 同事手工 / 需服务端。
```

## 4. 任务总表


> **计数复核**：总表行数 = 域表加和 = 逐项加和。防 38/41/42 漂移（反模式 #72）。

