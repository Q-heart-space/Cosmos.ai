# 深度治理规划

> **它解决什么**：🅑 深挖很容易**挖着挖着就散了** —— 🅑 或**停在"很深刻"而没有动作**。
> **它的立场**：🎯 **深挖的终点是**一份可执行分解**·🛑 不是一段洞见**。

---

## 一、🎯 何时继续挖·何时停

| 🎯 判 | 🎯 行 |
|:--|:--|
| 🅑 **新一层能推出新动作** | 🎯 **继续挖** |
| 🅑 **新一层只是换个说法** | 🛑 **停**（🅑 已到底） |
| 🅑 **再挖需要外部信息** | 🅑 **停下来去取**（🅑 别硬推） |

---

## 二、🎯 分解计划的四要件

| 🎯 件 | 🎯 判 |
|:--|:--|
| **可执行** | 🅑 每一项**有动作与产出** |
| **可验证** | 🅑 每一项**有验收判据** |
| **有依赖序** | 🅑 哪项**卡着**哪项 |
| **有回退** | 🅑 **做不成时怎么办** |

## 四、边界 / Boundaries

- 🅑 本件是**规划方法** —— 🅑 不替你决定治理的方向；
- 🅑 深度之判**随场景而异** —— 🅑 本件只给"何时停"的判据；
- 🅑 本件**不含**任何具体的治理决策。
