# common/ — 跨行业共性决策单元 / Cross-industry common decision units

本目录承载**抽取出的共性决策单元**——当 ≥2 个行业出现同一决策结构时，该结构上提到此，行业目录只保留差异。

This folder holds **extracted common decision units**. When ≥2 industries share the same decision structure, it is promoted here; industry folders keep only the differences.

## 收录判据 / Inclusion criteria

| # | 判据 / Criterion |
|:--|:--|
| 1 | ≥2 个行业出现同一决策结构（同依据／同替代集／同验收标准） |
| 2 | 与行业无关的表述（不绑定具体产品/客户/区域） |
| 3 | 五元组齐备（依据／替代／验收／证据链／授权+收据链） |
