# memory/ — 可移植的记忆制品 / Portable memory

本域收录**与实例无关**的记忆制品。面向「**我要一套同样的记忆与规则**」的使用者。

Portable memory artifacts that are independent of any particular instance — for people who want the
same memory and rules to take root in their own system.

## 收录判据 / Inclusion criteria

1. 🎯 **可移植** —— 与实例无关，**检出即可落位**（🅑 本域之制品自陈「供无正本的机器落位」）；
2. 🎯 **含清单** —— 收、发双方**可核**；
3. 🎯 **无私有凭据／路径** —— 机器相关的写法须解析式化。

## 边界 / Boundaries

- 🛑 **会话／机器私有态不入**；
- 🛑 含他人隐私信息者不入；
- 🅑 品牌／主体专属命名须**外置为使用者自填**。
