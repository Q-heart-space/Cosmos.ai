## 子目录 / Subfolders

```
methodology/

```

## 收录判据 / Inclusion criteria

| 条件 | 说明 |
|:--|:--|
| **① 可迁移** | 换一个业务场景仍成立——只对某一家有效的做法不收 |
| **② 可复现** | 给出**步骤与判据**，读者能照着做一遍并自检 |
| **③ 有出处** | 指明它从哪次实践来（场景 → 问题 → 做法 → 结果）——无出处的不收 |
| **④ 已脱敏** | 剥离内部实现细节（路径、主机名、凭据、内部代号） |

## 收什么 · 不收什么 / What belongs here

| 收 | 不收 |
|:--|:--|
| 做法、步骤、判据、检查清单 | 单次结论、一次性数据 |
| 换场景仍成立的方法 | 只对本项目成立的实现细节 |
| 失败教训（含「此路不通」） | 未验证的构想 |

## 怎么进 / How to add

1. 在 `case/` 下按「一个方法论一目录」建目录（用英文小写短横线命名）。
2. 目录内写 `README.md`，按上面四条判据写成「场景 → 问题 → 做法 → 结果 → 可迁移点」五段。
3. 跑一次脱敏检查（④），确认无内部痕迹后提交。
4. 发布走标准发布流程（见仓库根 `CONTRIBUTING.md`），过域门禁后才进本目录。
