# FDE 接入五章骨架

> 知识型技能：**不执行、不产判断、不做裁决**；只承载「接入流程骨架」这一知识件。
> 正文见 
eferences/five-chapter-skeleton.md（含五章、六项验收、回滚、边界自陈）。

## 用法

1. 按 
eferences/five-chapter-skeleton.md 的 S1→S5 顺序执行；
2. 每章跑其「判据」命令，失败按「失败处置」处理；
3. 五章通过后跑「验收六项」（A1–A6）；
4. 需要回滚时按「回滚 ≤4 步」。

## 边界（🛑）

- 不含对外承诺/商务条款（属服务交付面 deliverables/）；
- 不含真实案例与客户数据（全部以 <域>/<组织> 占位）；
- 真实第二组织端到端**未验**（仅结构演练）。
